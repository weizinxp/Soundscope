# 🇧🇷 Português

## 🎵 Sobre o Projeto

O SoundScope é uma plataforma de análise musical que reúne dados de diferentes serviços de streaming para fornecer estatísticas, recomendações e insights personalizados sobre hábitos musicais.

O objetivo é transformar seu histórico musical em informações úteis e visualmente agradáveis.

### ✨ Funcionalidades

* 📊 Dashboard musical
* 🎧 Integração com Spotify
* 🎵 Integração com YouTube Music
* 📝 Recomendações baseadas em letras
* 🎯 Recomendações por gênero musical
* 👤 Perfil personalizado
* 💬 Fórum da comunidade
* 📈 Análise de tendências musicais

### 🛠️ Tecnologias

#### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS

#### Backend (Planejado)

* Python
* FastAPI

#### Banco de Dados (Planejado)

* PostgreSQL

#### Análise de Dados (Planejada)

* Pandas
* Scikit-Learn
* Matplotlib

# 🇺🇸 English

## 🎵 About The Project

SoundScope is a music analytics platform that combines data from different streaming services to provide personalized statistics, recommendations and insights about listening habits.

The goal is to transform your listening history into meaningful and visually engaging information.

### ✨ Features

* 📊 Music Dashboard
* 🎧 Spotify Integration
* 🎵 YouTube Music Integration
* 📝 Lyrics-Based Recommendations
* 🎯 Genre-Based Recommendations
* 👤 Personalized Profile
* 💬 Community Forum
* 📈 Music Trend Analysis

### 🛠️ Technologies

#### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS

#### Backend (Planned)

* Python
* FastAPI

#### Database (Planned)

* PostgreSQL

#### Data Analytics (Planned)

* Pandas
* Scikit-Learn
* Matplotlib
